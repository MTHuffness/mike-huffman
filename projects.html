MTHuff Morpheus

Real-Time LLM Market Adjudication

A real-time LLM decision system for market-regime analysis, engineered with the rigor of a test suite — a defined ground truth, a null hypothesis, and a measured ceiling.

  • ▶Measurable, Causal Evaluation: A walk-forward harness replays market sessions bar-by-bar while an LLM adjudicates regime shifts strictly causally (no lookahead), scored against hand-labeled ground truth — 0.81–0.84 label occupancy vs. a 0.62 mechanical baseline, roughly 90% of the ceiling established by an oracle adjudicator.
  • ▶Cost-Engineered Eval Loop (100× Cheaper Iteration): Distills each session into ~35 pivotal decision points, rebuilds them as byte-identical single-turn prompts, and batch-grades them for ~$1/session vs. $7 for a full run — plus a free tier using transcript replay and local-model adjudication.
  • ▶Doctrine Compiler: Every human annotation is automatically compiled (~1¢ a pass) into durable, structured rules with provenance and hash-based change tracking, feeding the production system prompt as a versioned, admin-reviewable rulebook — expert knowledge flows into model behavior with zero manual prompt editing.
  • ▶Reproducibility & Regression Infrastructure: Every adjudicator call is transcript-logged, runs replay offline bit-identically, the baseline is frozen and regression-checked after any harness change, and failed eval moments re-run in isolation with controls.
  • ▶End-to-End Outcome Measurement: A trade-simulation engine walks the full trading methodology over any model-generated timeline, converting classification accuracy into dollars-and-cents P&L per session — including an oracle ceiling quantifying each day's maximum tradability.
